CTF-012C
Eliminate API / Worker Lost Updates
Priority: P0 — Critical

Tasks
Remove full-snapshot overwrite behavior from document worker persistence.

Ensure worker never writes an outdated complete repository snapshot.

Make worker persistence delta-based or entity-level.

Ensure worker reads fresh project/resource state immediately before processing.

Ensure worker writes only document-processing-related changes.

Prevent worker updates from deleting or overwriting concurrent API changes.

Make all worker persistence transactions merge-safe.

Add optimistic version/conflict checks where necessary.

Required Test
Scenario:

1. Start worker repository
2. Start API repository
3. Worker begins document processing
4. API creates new QUESTION
5. Worker completes document processing
6. Reload repository from PostgreSQL
Expected:

QUESTION still exists
Document processing changes exist
No unrelated project state is lost
Required Tests
test_worker_does_not_overwrite_concurrent_api_resource
test_worker_preserves_concurrent_question
test_worker_preserves_concurrent_evidence
test_worker_preserves_concurrent_gate_decision
test_worker_delta_persistence_updates_only_document_entities
test_worker_detects_version_conflict
